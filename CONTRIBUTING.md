# Contributing to DocuScan AI

Thank you for helping improve this open-source project.

## Before you start
- Check existing issues and pull requests to avoid duplicate work.
- Open an issue to discuss substantial changes before implementing them.
- Be respectful and constructive in discussions.

## Local setup
1. Install Node.js and npm.
2. Clone this repository and run `npm install`.
3. Start development with `npm run dev`.
4. Run `npm run lint` and `npm run build` before submitting a pull request.

## Pull requests
- Keep each PR focused on one fix or feature.
- Explain the motivation, changes, and how you tested them.
- Include screenshots for visible UI changes.
- Never commit credentials, personal scans, API keys, or private documents.
- Make sure you have rights to contribute all code and assets.

## Reporting bugs
Please include reproducible steps, expected and actual results, browser/OS versions, and redacted logs. Do not upload personal documents.

## Scope
The README may describe planned or native reference features. Verify the actual implementation before reporting any feature as production-ready.
