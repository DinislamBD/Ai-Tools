# Security Policy

## Reporting a vulnerability

Please do **not** disclose exploitable vulnerabilities in public GitHub issues.

Contact the repository maintainer privately through their GitHub profile or use GitHub's private vulnerability reporting feature if enabled. Include a minimal reproduction, affected versions, and impact. Do not include real identity documents, scans, or other sensitive data.

## Sensitive data

Never commit API keys, tokens, passwords, or real user documents. Test document workflows with synthetic sample data.

## Support status

This is a community-maintained project. No guaranteed security response time or audited release is claimed. Users should independently evaluate suitability before processing sensitive documents.
